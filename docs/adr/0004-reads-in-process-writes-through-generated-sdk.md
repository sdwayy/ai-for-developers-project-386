# Чтения идут из серверного data-модуля, записи — через сгенерированный SDK

Фронтенд разводит данные по направлению движения: Server Components читают серверный data-модуль in-process, минуя HTTP-контракт, а Client Components пишут по HTTP через сгенерированный клиент за рукописным фасадом. Так предписывает Next 16 — читать данные в Server Components напрямую из источника: поход за чтением через Route Handlers ломает пререндер, добавляет лишний round trip и требует абсолютного URL. `/api` остаётся единственной точкой записи, а правила дня, окна записи и нарезки слотов живут только в серверном data-модуле.

Артефакты генерации лежат в `src/shared/api/generated/`, серверный data-модуль — в `src/shared/api/server/` и помечен `import "server-only"` (его импортируют и Server Components, и Route Handlers), рукописный фасад — публичный API слайса `src/shared/api/index.ts`, а корневые `app/api/**/route.ts` остаются тонкими: разбор → валидация сгенерированными схемами → вызов data-модуля → `Response.json`. Фасад поверх машинного вывода держит базу URL `/api`, маппинг `ErrorCode` в русские тексты и реэкспорт типизированных операций, чтобы фичи и страницы не зависели от формы `generated/*`; прямой импорт `@/shared/api/generated/*` вне `src/shared/api/**` запрещён.

**Considered Options**: всё через HTTP-контракт из Server Components — отклонено: пререндер ломается без абсолютного URL, плюс лишний round trip; Server Actions вместо HTTP-контракта — отклонено: контракт уже HTTP, а UI обязан различать `ErrorCode`; прямой импорт сгенерированного клиента в фичах — отклонено: форма машинного вывода и базовый URL протекли бы в фичи, рукописный фасад даёт одну точку правки.

**Consequences**: GET-операции контракта UI не вызывает — их покрывают тесты Route Handlers, а правила дня, окна и нарезки слотов тестируются юнит-тестами data-модуля; клиентская zod-валидация форм остаётся в фичах и в фасад не переезжает; граница данных доказывается в CI oxlint-запретами — `no-restricted-globals` на `fetch` везде, кроме `src/shared/api/generated/**`, и `no-restricted-imports` на `@/shared/api/generated/*` вне `src/shared/api/**`, — плюс компонентным тестом, что флоу подтверждения зовёт фасад; слои `entities`/`features` пока не вводим.
