# Внедряем Feature-Sliced Design поверх Next.js App Router

Мы приняли FSD как архитектурную основу фронтенда. Слои FSD живут в `src/`, а каталоги роутинга Next.js (`app/`) остаются в корне и содержат только тонкие реэкспорты из `@/_pages/*`. Чтобы имена слоёв FSD не конфликтовали с каталогами фреймворка, слой `app` переименован в `_app`, а `pages` — в `_pages`. Импорты допускаются только из слоёв ниже и только через публичный API слайса (`index.ts`); соответствие путей задано алиасами в `tsconfig.json`.

**Considered Options**: оставить обычную структуру Next.js (логика прямо в `app/`) — отклонено, потому что методология FSD требует явных границ слоёв; перенести роутинг Next под `src/app` — отклонено, официальный гайд FSD рекомендует держать каталоги роутинга фреймворка в корне проекта.

**Consequences**: настройка Mantine-провайдера и темы переехала из корневого `theme.ts`/`app/layout.tsx` в `src/_app/providers`; `AGENTS.md` синхронизирован с новой раскладкой.
